Install

Three commands to a report.

Python 3.11+ · read-only · credentials stay on your machine. On PyPI, installable with pip and pipx.

1

Install PipelineProbe

pipx install pipelineprobe

Or pin the v0.3.1 release wheel: pipelineprobe-0.3.1-py3-none-any.whl.

2

Create a config

pipelineprobe init

Writes pipelineprobe.yml with sensible local defaults.

3

Run the audit

pipelineprobe audit --config pipelineprobe.yml

Reports land in ./reports/ as HTML and JSON; open pipelineprobe-report.html in any browser.
